# AIDS Virus Infection Prediction

A machine learning classification project focused on predicting HIV infection status using patient data.

## Overview

This project explores and compares different machine learning algorithms to classify whether a patient is infected or not based on clinical and demographic features.

## Workflow

- **Exploratory Data Analysis:** Dataset inspection, statistical analysis, missing value checks, and visualizations.
- **Data Preprocessing:** Categorical feature conversion, outlier handling using the 3-sigma method, One-Hot Encoding, and Standard Scaling.
- **Model Training & Evaluation:** Comparing 13 classification algorithms using 5-fold cross-validation.
- **Visualization:** Comparing model performance through accuracy scores and plots.

## Algorithms

- K-Nearest Neighbors
- Linear SVM & RBF SVM
- Gaussian Process
- Decision Tree
- Random Forest
- Multi-Layer Perceptron (Neural Network)
- AdaBoost
- Gaussian Naive Bayes
- Quadratic Discriminant Analysis
- LightGBM
- CatBoost
- XGBoost

## Technologies

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
- LightGBM
- CatBoost
- XGBoost

## Dataset

The project uses the **AIDS Classification Dataset**, containing patient-related features and a binary infection status label (`infected`).

*This project is intended for educational and experimental machine learning purposes, not for clinical diagnosis.*
